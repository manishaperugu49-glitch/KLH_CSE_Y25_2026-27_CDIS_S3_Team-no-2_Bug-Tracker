Cloud-Based Software Bug Tracking and Issue Management Platform
Project Overview
Our project is a cloud-based platform used to report, assign, track, and resolve software bugs in one place.

It helps testers, developers, and managers work together and manage software issues easily.

Problem Statement
In traditional methods, bugs are reported through emails, chats, and spreadsheets. This can cause lost reports, duplicate issues, unclear responsibilities, and delays in fixing bugs.

Our project provides one centralized platform to solve these problems.
Objectives
- Make bug reporting easy.
- Assign bugs to developers.
- Track bug status.
- Improve teamwork and communication.
- Resolve bugs faster.
Main Features
1. User Login: Secure user login with role-based access.
2. Bug Reporting: Users can report bugs with titles, descriptions, severity, and screenshots.
3. Bug Assignment: Managers can assign bugs to developers.
4. Status Tracking: Track bugs as Open, In Progress, Resolved, or Closed.
5. Comments and Alerts: Users can discuss bugs and receive notifications.
6. Dashboard: View, search, and filter bug reports.
How the Project Works
1. User logs into the platform.
2. User reports a software bug.
3. Manager assigns the bug to a developer.
4. Developer works on the bug and fixes it.
5. The status is updated.
6. After verification, the bug is closed.
AWS Services Used
- Amazon EC2: Hosts the application and backend.
- Amazon RDS: Stores user and bug information.
- Amazon S3: Stores screenshots and attachments.
- Amazon Cognito: Handles user registration and login.
- Amazon SNS: Sends email notifications.
- Amazon CloudWatch: Monitors application performance and logs.
Benefits
- Centralized bug management.
- Faster bug resolution.
- Better communication.
- Clear responsibility.
- Easy tracking of project progress.
- Cloud-based accessibility and scalability.
Conclusion
Our project provides a centralized platform to manage software bugs efficiently. It helps teams report, assign, track, and resolve issues while improving collaboration and software quality. The proposed AWS services support hosting, storage, authentication, notifications, and monitoring.
