# CLOUD-BASED SOFTWARE BUG TRACKING AND ISSUE MANAGEMENT PLATFORM

## 1. PROJECT OVERVIEW

Our project is a cloud-based platform used to report, assign, track, and resolve software bugs in one place.

It helps testers, developers, and managers work together to manage software issues easily and efficiently.

## 3. PROBLEM STATEMENT

Traditionally, software bugs are reported through emails, chats, and spreadsheets. This can cause lost reports, duplicate issues, confusion, and delays in fixing bugs.

Our project provides a centralized platform to solve these problems.

## 4. OBJECTIVES

- Make bug reporting easy.
- Assign bugs to developers.
- Track bug status.
- Improve communication and teamwork.
- Resolve bugs faster.

## 5. MAIN FEATURES

1. **User Login:** Allows users to securely log in.
2. **Bug Reporting:** Users can report bugs with descriptions and screenshots.
3. **Bug Assignment:** Managers can assign bugs to developers.
4. **Status Tracking:** Tracks bugs as Open, In Progress, Resolved, or Closed.
5. **Comments and Alerts:** Allows users to discuss bugs and receive notifications.
6. **Dashboard:** Helps users view, search, and filter bug reports.

## 6. WORKING OF THE PROJECT

1. The user logs into the platform.
2. The user reports a software bug.
3. The manager assigns the bug to a developer.
4. The developer works on the bug and fixes it.
5. The developer updates the bug status.
6. After verification, the bug is closed.

## 7. AWS SERVICES USED

1. **Amazon EC2:** Hosts the application and backend.
2. **Amazon RDS:** Stores user and bug information.
3. **Amazon S3:** Stores screenshots and attachments.
4. **Amazon Cognito:** Handles user registration and login.
5. **Amazon SNS:** Sends email notifications.
6. **Amazon CloudWatch:** Monitors application performance and logs.

## 8. BENEFITS

- Centralized bug management.
- Faster bug resolution.
- Better communication.
- Clear responsibility.
- Easy tracking of project progress.
- Cloud-based accessibility and scalability.

## 9. CONCLUSION

Our project provides a centralized platform to manage software bugs efficiently. It helps teams report, assign, track, and resolve issues while improving collaboration and software quality.

The proposed AWS services support application hosting, data storage, authentication, notifications, and monitoring.
